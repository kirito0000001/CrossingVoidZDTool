# 特效层预览「重复播放 / 闪烁」—— 问题档（2026-09-25，**未解决**）

> 这一天试了七八个方向都没修好，最后 **git 回退**了。
> 这份档的价值不在"结论"，而在 **① 已经排除了什么 ② 怎么自己验证** —— 下次别从头猜。

---

## 现象（晓桀的原话，按发生顺序）

1. 「特效帧预览播放时**有些图片闪烁**，特效播得快，一闪就看不见了」；
2. 「**所有**帧都闪，从一帧到下一帧就会闪（**加载跟不上播放**），然后**特效就全看不见了**」；
3. 「遇到**最后几帧或者比较长的帧**就会闪…**特效播放的时机不对**…有**重复播放**的 BUG」；
4. 「**这两帧来回播放了三次**」（配图：时间轴高亮在第 3 格 ↔ 第 4 格来回，火花跟着出现/消失）。

**复现用的动作**：`Defence` ——
3 个素材帧，格数 **3 / 1 / 1**（共 5 格）；特效层 7 帧（空 3），倍数 **2** → 展开后 **10 格**。
播放参数：`fps = 12`，**循环播放开着**，「预览叠特效」开着。

## 已经**排除**的（都有一手证据，别再往这些方向猜）

| 假设 | 结论 | 证据 |

| 呈现层缺"提前把下一格 Prepare 到暗的那张" | 补上了、**仍闪** | 实测 |
| 特效帧没建成"逐格序列"（还在按序号线性查） | 建了、**仍闪** | 实测 |

## 现在的**硬数据**（自己跑 `--ui-smoke` 跑出来的，不是推测）

```
切帧：2 → 0（第 6 次角色层 tick）（本帧格数=6）     ← 进入帧 0，它有 6 格
切帧：0 → 1（第 7 次角色层 tick）（原 counter=2）    ← 250ms 里只走了 2 格  ✗
切帧：1 → 2（第 8 次角色层 tick）（原 counter=6）    ← 83ms 里走了 6 格      ✗
```

→ 特效层那只 `1000/(fps×倍数)` = **42ms** 的定时器，实测 **125~250ms 才响一次**，而且**忽快忽慢** ✗。
（角色层同一时刻是准的 ✓，所以不是"整个 UI 卡"，而是**这只定时器被饿**。）

---

## 剩下的怀疑方向（**没验完**）

1. **这只定时器被 UI 饿着** —— 它每一格要做：换图 + 两个 presenter 的 `Show`/`Prepare` + 高亮同步 + `ScrollIntoView`。
   → 削开销（滚动已经试过降到每 4 格一次，**没有验证够不够**）；
2. **换驱动方式** —— 让它跟着**渲染帧**走（`CompositionTarget.Rendering`），
   或者由角色层 tick 按"时间差"驱动，而不是靠高频 `DispatcherQueueTimer`；
3. **反向可能**：如果实测证明它并没有被饿（42ms 很准），那就回到「**谁在改 `_sequenceEffectSubFrame`**」上查。

---

## 试过但**撤掉**的（别再重复这两条）

1. `AdvancePreviewFrame` 里加"按格数 / 按时间停留" → **错**：
   定时器的 `Interval` 本来就是 `格数/fps`（`UpdateSequencePreviewInterval()`），
   等于**同一件事算两遍** ✗（日志：6 格的帧走了 12 个 increment = 播了两轮）；
2. `_sequenceEffectSubFrame += steps`（"迟到就补格"）→ **错**：
   补出来的步数忽大忽小（上面那两行数据就是它造成的），只会让快慢更乱 ✗。

## 怎么**自己验证**（这条最值得留）

```powershell
# 跑之前先把正在运行的工具箱关掉 —— exe 被占用会报 MSB3021 ✗
dotnet build CrossingVoidZDTool.csproj -c Debug -p:Platform=x64
bin\x64\Debug\net8.0-windows10.0.19041.0\win-x64\零境交错：ZD工具箱.exe --ui-smoke "D:\ui-smoke.txt"
```

- **不带 `-p:Platform=x64` 会报** `WindowsAppSDKSelfContained requires a supported Windows architecture` ✗；
- `--ui-smoke` 是**进程内的 UI 冒烟**（用 automation peer 点自己窗口里的控件 ✓，不改用户数据、写完报告自己退出）；
- **可以加钩子**让它跑到指定场景：照 `MainWindow.*.cs` 里的 `UiSmokeShowXxxPage()` 一族写
  （`UiSmokeShowSt5Page()` / `UiSmokeShowCharacterDeskPage()` …）；
- ⚠️ **坑**：`SequenceFrames.TrySelectSection("Defence")` 只切 VM 的选中，
  **还要自己调 `ReloadEffectLayer(character, section)`**（正常路径是"打开编辑器"那处做的）
  —— 否则特效帧根本没从磁盘读出来，日志里一条 `Effect Cursor` 都不会有 ✗；
- 跑完读 `%LOCALAPPDATA%\CrossingVoidZDTool\Logs\runtime.log`（有按天轮转）。
